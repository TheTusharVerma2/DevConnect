# DevConnect Client Web Application

DevConnect is a social platform for developers to showcase public GitHub projects, publish code updates, follow fellow engineers, and engage in community discussions.

## Key Features

- **Developer Profiles**: Customize your bio, skills tags, experience, education, and social links.
- **Automated GitHub Showcase**: Sync and display your top public GitHub repositories and star counts directly on your profile.
- **Community Feed**: Post updates with code images, like peer posts, and participate in nested comment threads.
- **Personalized & Global Feed**: Switch between the global developer feed and a personalized feed of engineers you follow.
- **Developer & Post Search**: Instant search across developer profiles, tech skills, and community discussions.

## Getting Started

First, launch the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the platform.
